\begin{enumerate}
\item \textbf{V9990 check.} The MSX output shows Topo Soft 1990, V9990 DiHalt Studio 2026 and the V9990 detection result. These messages remain there while you play on the V9990 output.
\item \textbf{DiHalt Studio.} Switch to the V9990 output. The logo stays for about nine seconds until its music finishes, then advances automatically.
\item \textbf{Opening illustration.} Press and release Control, Space, Enter, M or fire to continue.
\item \textbf{Topo Soft.} The animation advances automatically.
\item \textbf{Title.} The colour logo appears. Press and release any opening-screen input to advance.
\item \textbf{Credits and difficulty.} These stay on V9990. Choose \texttt{STANDARD / HARD} with cursor keys or the joystick, then confirm with fire. An arrow and green lettering show the selection; the default is \texttt{STANDARD}.
\item \textbf{Play.} Press fire when prompted, including the stage introduction and \texttt{READY}.
\end{enumerate}
After \texttt{GAME OVER}, you can start another game from the same difficulty menu, with STANDARD selected again.
